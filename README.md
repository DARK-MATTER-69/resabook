# ResaBook — Système de réservation en ligne

Application web de gestion de réservations (rendez-vous, services, salles).

## Stack
- Frontend : Next.js 14 (App Router), Tailwind CSS, shadcn/ui
- Backend : Django 5 + Django REST Framework
- Base de données : PostgreSQL
- Auth : JWT (SimpleJWT)

## Structure

├── backend/   # API Django
└── frontend/  # App Next.js
